Exit Intelligence

Liquidity tells part of the story. What can actually get out?

Elofid separates headline liquidity from verified executable exit capacity. Every value passes a production verification gate. A number that cannot be verified is never invented.

Reported liquidity
—
Displayed only from returned market data. Useful context, but not the same thing as executable sell depth.
real market context only
Verified Exit Depth · 10%
—
Returned as exact when the scan has complete supported coverage. With partial coverage it is a verified lower bound, shown as at least $X. A value that cannot be verified is never shown.
exact · at least · never invented

Built for integration
✓Create and manage tenant-scoped Watchlists and monitored assets through the API.
✓Read full My Monitoring Events and Risk Incidents on every plan. Starter+ unlocks the Global Feed API.

POST/v1/watchlists/{watchlist_id}/assets
REAL API CONTRACT
export ELOFID_API_BASE="https://api.elofid.com"
export ELOFID_API_KEY="YOUR_API_KEY"
export ELOFID_WATCHLIST_ID="..."
export TOKEN_ADDRESS="0x..."

curl -X POST "$ELOFID_API_BASE/v1/watchlists/$ELOFID_WATCHLIST_ID/assets" \
  -H "Authorization: Bearer $ELOFID_API_KEY" \
  -H "Content-Type: application/json" \
  -d "{\"chain\":\"base\",\"token\":\"$TOKEN_ADDRESS\"}"
Uses the production Elofid API domain. Get ELOFID_WATCHLIST_ID from GET /v1/watchlists, keep the API key server-side and treat the key value as opaque.
